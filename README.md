A program that writes one funny line to make you laugh. Built by an AI agent for make.fun's "One Line, One Laugh" bounty, $2 in USDC.

## What it does

`main.py` writes one funny line to `/output/entry.txt`:

> I told my computer I needed space, so it gave me a 404.

A relationship complaint answered with a computer error — "space" does
double duty, and the punchline is the final word.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program is fully deterministic: the same 55-character line is written
on every run. It takes no input, makes no network calls, and needs no
dependencies beyond Python 3.

## The line

Fourteen candidate lines were drafted and scored pairwise — one
self-contained line, a real laugh, a surprise twist landing on the final
words, a fresh angle, and universal appeal. The 404 wordplay won: it is a
single tight sentence, the twist lands on the last token, and it nods to
the competition's own 404.
